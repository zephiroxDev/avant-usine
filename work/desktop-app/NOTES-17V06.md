# Avant l’usine — Windows 0.3.6 · 17V06

- Chaque morceau peut être partagé directement depuis la liste ou le lecteur. Le lien ouvre le morceau et un panneau avec son auteur, son profil si disponible et la première date de création. Les partages sans compte sont indiqués comme anonymes. Copie du lien et menu de partage de l’appareil lorsqu’il est disponible.
- Les ateliers Highlight Progression et synchronisation avancée proposent 0,50×, 0,75×, 1× et 2×. Le changement de vitesse conserve la progression et les repères enregistrés, toujours exprimés dans le temps réel du morceau. Le brouillon conserve la vitesse choisie ; fermer l’atelier rétablit celle du lecteur.
- Choix du format avant import : Highlight Progression accepte les JSON détaillés ; les fichiers LRC et les JSON avec de simples départs de lignes utilisent synchronisation simple. Le fichier original reste conservé. L’approbation demande toujours une prévisualisation complète.
- Infos, fonctionnalités & astuces complété dans Lire le reste.

La mise à jour de l’installation existante est proposée dans l’application. Les paramètres et données locales sont conservés.
