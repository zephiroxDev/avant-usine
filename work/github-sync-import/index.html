    Comment écouter directement sur le site ?

    Ouvre la rubrique Écoute, choisis un volume puis un morceau. Le lecteur reste présent quand tu navigues entre les rubriques de ce site.

    Comment récupérer un volume complet ?

    Le bouton de téléchargement ouvre MEGA dans un nouvel onglet. Télécharge le ZIP puis extrais-le pour retrouver les fichiers audio individuels.

    Et les prochains volumes ?

    Leurs pochettes sont visibles dans la collection. L’écoute et le téléchargement seront proposés au fil des sorties.
