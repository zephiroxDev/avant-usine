# 19V00 — Atelier et projets en cours

État : publié et vérifié — site 19V00, Windows 0.5.0, Android 0.2.0, iOS 1.1.0.

Priorité UX : interface extrêmement simple malgré toutes les fonctions. Capture, lecture/pause et annuler visibles ; opérations contextuelles à la sélection ; outils avancés repliés par défaut. Les messages utilisateur pendant le travail ne mettent pas fin au travail : répondre puis reprendre automatiquement.

## Périmètre accepté

- Capture à un bouton / Espace, phrases puis mots facultatifs, vitesse réelle des minutages.
- Pistes indépendantes principale, backs, ad-libs et personnalisées ; chevauchements libres.
- Timeline, zoom, forme d’onde, débuts/fins/mots indépendants, reprise depuis un mot.
- Boucle avec préécoute ; décalage des sélections/pistes ; couper/fusionner ; dupliquer un refrain.
- Modifier le texte ; supprimer une phrase ; annuler/rétablir ; verrouiller ; sauvegarde automatique.
- États à faire / à revoir / terminé par phrase et piste ; aperçu lecteur.
- Validation avant export ; JSON multipiste et LRC simple avec avertissement explicite des pertes.
- Mes projets en cours pour tous les comptes, privés : reprendre, renommer, archiver, supprimer ; disponibilité locale audio explicite.
- Compatibilité brouillons existants et propositions de modération ; limites serveur à adapter.
- Responsive PC/mobile et toutes applications ; historiques publics, guide Lire le reste, une affiche originale Gestion promo.
- Gestion promo privée : même fiche et même case Publiée pour PNG et version animée MP4 ; effets lumineux sans déplacement du texte ; ne pas inclure cet outil privé dans les notes publiques.

- Mode immersion applications uniquement : disposition Scène validée, pochette en décor plein écran floutée pour rendre ses inscriptions illisibles ; paroles et commandes nettes au premier plan, disposition responsive ordinateur/téléphone. Aucun flou sur les paroles.

## Livraison

Site et applications publiés séparément dès validation. Versions techniques à fixer après préparation. Ne pas déclarer une fonctionnalité terminée sans validation fonctionnelle.
